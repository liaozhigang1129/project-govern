## 功能
1. **列表**
   - 7 列:ID / 时间 / 用户 / 资源(类型+#id) / 动作 / 结果 / IP / 详情
   - 颜色:动作 (CREATE=绿,UPDATE=黄,DELETE/REJECT=红,LOGIN/LOGOUT=蓝)
   - 结果:SUCCESS(绿)/ FAILURE(红)

2. **筛选**
   - 资源类型(AUTH/INITIATION/MILESTONE/PROJECT/HEALTH_ADVISOR)
   - 动作(11 种,含 LOGIN/REFRESH/LOGOUT/CREATE/UPDATE/...)
   - 用户ID(el-input-number)
   - 起止时间(el-date-picker,ISO 格式)
   - 空 = 后端默认 7 天窗口

3. **分页**
   - size 10/20/50/100,max=100
   - total/totalPages 同步

4. **详情抽屉(60% 宽)**
   - 字段:ID/时间/用户/资源/动作/IP
   - Payload:黑底彩色 JSON(带缩进)+ 8KB 截断的 TRUNCATED 标记

5. **角色门控(两层)**
   - 前端:meta.roles=['PMO_ADMIN','ADMIN'] + visibleMenuItems
     - viewer 登录后,菜单看不到"审计日志"
     - 强行输 /audit-logs 路径 → 跳到 /
   - 后端:@PreAuthorize("hasAnyRole('PMO_ADMIN','ADMIN')")
     - 401/403 由 GlobalExceptionHandler 处理
