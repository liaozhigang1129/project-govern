## A5.9 切流日作战手册(T 时刻)

### A5.9.1 时刻表

| 时刻 | 动作 | 责任人 | 退出条件 |
| --- | --- | --- | --- |
| T-2h | 启动作战室 + 钉钉/飞书群启用 + 状态白板 | PMO-D | 所有人签到 |
| T-1h | 启动慢速灰度 1%(影子流量,无业务写入) | OPS-L | 影子流量 100% 200 OK |
| T-30m | 灰度 5%(写双写双读,主库仍为旧库) | DEV-L | 数据对账误差 < 0.01% |
| T-15m | 业务 + 治理联合评审 | PMO-D + BU-O | 决策放行 |
| **T** | **切流 50%(主库切换到新库)** | OPS-L | 业务 0 异常 |
| T+15m | 切流 100% | OPS-L | 业务 0 异常 |
| T+30m | 旧库切只读 + 持续对账 | DBA-L | 对账误差 < 0.1% 持续 30 分钟 |
| T+1h | 业务正式公告(全员) | PMO-D | 公告发出 |
| T+2h | 紧急回退决策点(若出现 P0) | PMO-D + 高管 | 决策继续 / 回退 |
| T+24h | 切流完成总结 + 进入稳态巡检 | PMO-D | 总结报告 |

### A5.9.2 异常分级与处置

| 级别 | 现象 | 处置 | 时间窗 |
| --- | --- | --- | --- |
| **P0 紧急** | 业务中断 / 数据损坏 / P95 > 5s | 立即回退到旧库,5 分钟内启动回退脚本 | 5 分钟内 |
| **P1 严重** | 关键流程失败 / 数据对账误差 > 0.1% | 暂停切流,30 分钟内决策继续 / 回退 | 30 分钟内 |
| **P2 一般** | 非关键接口异常 / 体验问题 | 记录 + 修复 + 灰度重启 | 当日修复 |
| **P3 提示** | 监控告警 / 性能波动 | 记录 + 观察 | 24 小时闭环 |

### A5.9.3 切流决策树

```
[影子流量 1% OK?]
   ├─ 否 → 修复 → 重试
   └─ 是 ↓
[5% 双写对账误差 < 0.01%?]
   ├─ 否 → 排查 ETL → 重试
   └─ 是 ↓
[业务 + 治理 Go?]
   ├─ 否 → 暂停 + 重新评估(不超过 24h)
   └─ 是 ↓
[切流 50%]
   ├─ 异常 P0/P1 → 回退
   └─ OK ↓
[切流 100%]
   └─ 完成
```
