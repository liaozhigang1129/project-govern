# 数据库 (Database)

## 1. 三种环境

| 环境 | DB | 用途 |
|------|----|------|
| 生产 | MySQL 8.0 | 真实数据 |
| CI | PostgreSQL 16 | 验证迁移可移植性 |
| 测试 | H2 in-memory | 单测速度 + 隔离 |

## 2. Flyway 迁移

- **MySQL**: `backend/src/main/resources/db/migration-mysql/V*.sql`
- **PG**: `backend/src/main/resources/db/migration-pg/V*.sql`
- **H2**: 不走 Flyway, 用 `test-schema-h2.sql` (测试启动时执行)

### 2.1 命名

`V{版本号}__{描述}.sql` (双下划线)

例: `V6.0__approval_engine.sql`

### 2.2 幂等保护

字典 seed 必须幂等:

- **MySQL**: `INSERT IGNORE INTO role (code, name) VALUES ...`
- **PG**: `INSERT INTO role (code, name) VALUES ... ON CONFLICT (code) DO NOTHING;`

### 2.3 必加 UNIQUE 约束

字典表 (role / project_type / project_status / health_level / milestone_status / initiation_status / member_role / department / approval_step) 必有 `UNIQUE(code)`.

`app_user` 有 `UNIQUE(username)` + `UNIQUE(email)`.

`wbs_task` 有 `UNIQUE(project_id, wbs_code)`.

## 3. MySQL vs PG 差异

| 特性 | MySQL 8 | PG 16 | 迁移注意点 |
|------|---------|-------|------------|
| 自增 | `AUTO_INCREMENT` | `BIGSERIAL` / `GENERATED BY DEFAULT AS IDENTITY` | 各写各的 |
| 时间 | `TIMESTAMP DEFAULT NOW()` | `TIMESTAMPTZ DEFAULT NOW()` | 各写各的 |
| 文本 | `TEXT` | `TEXT` | 同 |
| 注释 | `COMMENT 'xxx'` 在列上 | `COMMENT ON COLUMN xxx IS 'xxx'` | 单独语句 |
| UUID | `CHAR(36)` | `UUID` 类型 | 各写各的 |
| JSON | `JSON` | `JSONB` | 各写各的 |
| 布尔 | `TINYINT(1)` | `BOOLEAN` | 各写各的 |

## 4. 重置开发库

```bash
# MySQL
docker exec -it pmo-mysql mysql -uroot -p
DROP DATABASE pmo_dev;
CREATE DATABASE pmo_dev;
# 重启后端, Flyway 自动 migrate

# PG
docker exec -it pmo-pg psql -U pmo
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
```

## 5. 备份

### 5.1 MySQL

每日 cron:
```bash
mysqldump -uroot -p pmo_dev | gzip > /backup/pmo_$(date +%F).sql.gz
```

S3 上传 (保留 30 天)。

### 5.2 PG (CI)

CI 验证用, 不备份。

## 6. 索引策略

- 主键: BIGINT 自增
- 外键必加索引
- 字典 code 必加 UNIQUE 索引
- 软删字段 `deleted` 加 `INDEX (deleted)`
- 高频查询: `project_id` / `created_at` 加索引

## 7. 慢查询

开启慢查询日志:
```sql
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 1;  -- 1 秒
```

分析: `mysqldumpslow -s t /var/log/mysql/slow.log | head -20`.
