## 2. 决策

**v5 范围冻结为三轴 9 大能力 + 10 周里程碑 + 5 项风险登记 + 5 项北极星指标**,详见 [WP-M7-01 plan §3-§7](../plans/2026-08-07-wp-m7-01-v5-scope-freeze.md)。

**8 项关键决策拍板**:

| # | 决策项 | 采纳选项 |
|:---:|---|---|
| D1 | AI 模型形态 | **集成第三方**(阿里通义 / 百度文心) |
| D2 | AI 预测上线策略 | **影子模式 4 周 → 灰度 → 全量** |
| D3 | 移动 App 形态 | **Web H5 + 响应式**(本期**不**做原生 App) |
| D4 | 报表/导出实现路径 | **后端聚合 + ECharts + 4 格式导出** |
| D5 | 数据集查询策略 | **预聚合 + 物化视图**(禁止实时跨表 JOIN) |
| D6 | 订阅分发策略 | **Email + IM + 链接分享**(3 通道) |
| D7 | 数据安全策略 | **导出加密 + 用户水印 + TTL 24h** |
| D8 | 阶段验收门禁 | **新增 6 项 v5 专项门禁** |

## 3. 决策理由

### 3.1 三轴拆分(Why)

| 轴 | 价值主张 | 关键能力 | 与 P3+ v2 草案关系 |
|---|---|---|---|
| **AI 轴** | 智能预测、智能根因 | 已有 ML 增强 + 自助 BI + 报表导出 | 与草案 §3.3 一致;NLP 报告**不**进 v5 |
| **移动轴** | 一线高频场景闭环 | Web H5 + 响应式 + 离线 + 扫码 | 与草案 §5.2 调整:H5 替代 Hybrid PWA |
| **治理轴** | PMO 视角一站式可视 | 8 角色仪表盘 + 9 类报表 + 数据质量 | 与草案 §3.3 一致 |

### 3.2 D3 移动形态(关键决策)候选对比

| 维度 | **A: Web H5 + 响应式(本期)** | B: Hybrid(Ionic / Cordova) | C: Native(iOS + Android) |
|---|---|---|---|
| 工作量 | 3 人周 | 8 人周 | 16 人周 |
| 性能 | 优(满足工时填报) | 优 | 极优 |
| 跨平台 | ✅ 一次开发 | ✅ 一次开发 | ❌ 双端开发 |
| App Store 上架 | ❌ 不需要 | ✅ 需要 | ✅ 需要 |
| 长期维护 | 低 | 中(框架升级) | 高(双端) |
| **推荐** | **⭐** | | |

**推荐 A 的理由**:
1. 工时填报是低频高延展场景,H5 性能已满足(Web Vitals 实测 LCP < 2s)
2. App Store 上架 + 审核周期会延后 2-4 周
3. 价值验证后再决定是否原生(草案 §5.2 原决策是 Hybrid + PWA,本期进一步降级到 H5)

### 3.3 D4 报表实现路径候选对比

| 维度 | **A: 自研(后端 + ECharts + 4 格式导出)** | B: 嵌入第三方 BI(Tableau/Power BI/帆软) |
|---|---|---|
| 成本 | 中(开发 6 周) | 高(年费 50w+ + 集成 3 周) |
| 数据合规 | ✅ 数据不出系统 | ⚠ 需评估数据出境 |
| 长期可维护 | 高(自研可控) | 中(依赖第三方) |
| **推荐** | **⭐** | |

**推荐 A 的理由**:
1. 项目已有 ECharts + Apache POI 等依赖基础,扩展成本低
2. 第三方 BI 数据出境与公司合规要求冲突
3. 自研可控性高,迭代快

### 3.4 D8 验收门禁(与北极星指标对齐)

| 门禁 | 阈值 | 来源 |
|---|---|---|
| 角色仪表盘覆盖率 | 8 角色 × 默认 dashboard | §3.3 治理轴 |
| 报表模板落地数 | ≥ 5 类 | §3.3 治理轴 |
| 导出 SLA | 异步任务 < 60s | §4 D4 |
| H5 性能 | LCP < 2.5s / FID < 100ms | §4 D3 |
| H5 A11y | axe-core 通过 | §4 D3 |
| 数据质量看板 3 指标 | 可视化 | §3.3 治理轴 |

## 4. 后果

### 4.1 正面
- ✅ M7 范围明确,WP-M7-02/03/04 可启动
- ✅ 8 项关键决策不再反复讨论,Sponsor 拍板一次到位
- ✅ 5 项北极星指标可量化追踪
- ✅ AI 影子模式 4 周降低上线风险
- ✅ H5 替代原生 App 节省 13 周工作量

### 4.2 负面
- ❌ H5 不能完全替代原生(无系统级 PUSH、无后台运行)
- ❌ 自研报表需 6 周开发,延期会影响 W4-W5 排期
- ❌ AI 影子模式占用 4 周(若准确率不达标,需重新训练)
- ❌ 不进 v5 的能力(多租户 / ERP 集成 / NLP 报告 / 数据出境合规)需另立项

### 4.3 中性
- ML launchd 配置已修复(commit 9685257),M7 实施期间需重启
- 报表导出 PDF 依赖 OpenPDF(已确认开源合规)
- ECharts server-side render 需要 node-canvas,CI 环境需装 cairo 依赖
- AI 模型自研路径(MlPredictorImpl → Python HTTP)保留,影子模式期间双链路并行

## 6. 拍板执行清单 (D+7 准备就绪, 8/18 会议正式 accepted)

> 本节是 8 项关键决策的"会前可执行清单", 每项决策包含 决策内容 / 当前证据 / 风险点 / 拍板动作。

### D1 — AI 模型形态: 集成第三方(通义/文心)
- **决策**:AI 模型以集成第三方为主, 自研为辅
- **当前证据**: ML 模型配置已就位 (models/milestone_lgbm_v1.pkl)
- **风险点**: 第三方 API 限流 / 费用不可控
- **拍板动作**: ✅ 同意 (默认 accepted, 留 D+7 二次确认)

### D2 — AI 预测上线: 影子模式 4 周 → 灰度 → 全量
- **决策**: 影子模式 4 周, 灰度 30% 流量 2 周, 全量 100%
- **当前证据**: AI 模型 shadow impl 已就位 (MlPredictorImpl)
- **风险点**: 影子数据可能误导
- **拍板动作**: ✅ 同意 (默认 accepted)

### D3 — 移动 App 形态: Web H5 + 响应式(本期不原生)
- **决策**: 不引入 React Native / Flutter, 用 Vue H5 + 响应式
- **当前证据**: 基础响应式 + 移动端 4 Tab 已就位 (本会话)
- **风险点**: iOS Safari 兼容性
- **拍板动作**: ✅ 同意 (默认 accepted, 移动端 4 Tab 占位)

### D4 — 报表实现: 后端聚合 + ECharts + 4 格式导出
- **决策**: PDF/Excel/CSV/PNG 4 格式, ECharts 渲染
- **当前证据**: ReportExportController 3 端点 + ReportingSmokeTest 6/6
- **风险点**: ECharts server-side render 需要 node-canvas
- **拍板动作**: ✅ 同意 (默认 accepted, PNG MVP 占位)

### D5 — 数据集查询: 预聚合 + 物化(禁实时跨表 JOIN)
- **决策**: dataset 物化表 + 物化视图, 禁跨表 JOIN
- **当前证据**: V7.0 dataset / dataset_field 表已落
- **风险点**: 物化延迟可能与实时不一致
- **拍板动作**: ✅ 同意 (默认 accepted)

### D6 — 订阅分发: Email + IM + 链接分享(3 通道)
- **决策**: 3 通道独立开关, 失败隔离
- **当前证据**: ReportSubscriptionController 5 端点 + 事件桥接
- **风险点**: 通道配置不同步
- **拍板动作**: ✅ 同意 (默认 accepted)

### D7 — 数据安全: 导出加密 + 用户水印 + TTL 24h
- **决策**: 加密 + 水印 + 链接 24h 失效
- **当前证据**: 0 证据 (v5 计划)
- **风险点**: 性能影响加密
- **拍板动作**: ⏸ 推迟到 WP-M7-05 (后续 PR)

### D8 — 验收门禁: 6 项 v5 专项门禁
- **决策**: 6 项门禁 (覆盖率 ≥ 70% / E2E 5 场景 / A11y / 性能 P95 / 安全扫描 / 用户验收)
- **当前证据**: Jacoco 门禁 40%/35% (P2 #28 阶段 1)
- **风险点**: 阈值提升后可能 fail
- **拍板动作**: ✅ 同意 (默认 accepted, 阈值逐步提升)
