# 6 成本、预算与工时管理

## 6.1 预算与核算

### 6.1.1 预算编制

- 维度：人力、外包、采购、设备、差旅、培训、咨询、风险准备金、税费、其他；
- 编制期：项目级、阶段级、WBS 节点级；
- 版本管理：草案 V0.*、审核中 V1.*、基线 V1.0；
- 多币种与汇率：实时取自财务汇率表；
- 与**资源计划/工时预估**自动联动校验。

### 6.1.2 预算审批与控制

| 编号 | 需求描述 |
| --- | --- |
| FR-6.1-01 | 多级审批：PM → PMO 财务 → 业务负责人 → 集团财务（按额度） |
| FR-6.1-02 | **预算控制策略**：硬控制（超支不允许提交）/软控制（允许但需说明） |
| FR-6.1-03 | 预算**占用（Encumbrance）**：申请 → 占用 → 实际 → 释放 |
| FR-6.1-04 | 预算**调整**走变更流程（关联变更单） |
| FR-6.1-05 | **EVM 偏差分析**：CV、SV、CPI、SPI、TCPI、VAC、EAC |
| FR-6.1-06 | 预算**结转**到下一阶段/年度的规则与审批 |
| FR-6.1-07 | 预算**分摊**到子项目/WBS 节点 |

### 6.1.3 成本归集

- 工时 × 人员成本率 = 人力成本；
- 与 ERP 应付/总账对接，自动归集采购、差旅、报销等实际成本；
- 成本按项目/WBS/部门/成本中心多维归集。

## 6.2 工时填报与审批

### 6.2.1 填报

| 编号 | 需求描述 |
| --- | --- |
| FR-6.2-01 | **日/周填报**，移动端优先；支持离线缓存与提交 |
| FR-6.2-02 | 工时单字段：日期、任务/工作项、时长、加班/休假、说明、附件 |
| FR-6.2-03 | 默认填写：8h/天 工作日历 + 加班自动提示 |
| FR-6.2-04 | 工时**审批**：直属上级（可按日/周批）；PM 可对项目内工时复审 |
| FR-6.2-05 | 批量填报：复制上一周期、按日历/任务复制 |
| FR-6.2-06 | **工时合规**：超 12h/天、连续工作超 6 天等异常提示 |
| FR-6.2-07 | 工时与任务/项目关联，**未关联视为无效**（可配置） |
| FR-6.2-08 | 工时锁定：已结算周期不允许修改，需解锁审批 |

### 6.2.2 工时与成本联动

- 工时 × 人员日费率 → 人力成本；
- 任务剩余工时 = 预估 − 实际（自动滚动）；
- 项目成本实时更新到预算与挣值。

## 6.3 报销与采购（联动）

- 报销：项目代码/任务代码/WBS 必填，预算占用校验；
- 采购：PR/PO/合同 → 关联项目 → 预算占用 → 入库 → 结算；
- 付款：按里程碑/验收节点付款，发票与项目里程碑绑定。

## 6.4 报表

- 项目预算 vs 实际（按类别/阶段/WBS/月份）；
- EVM 趋势图；
- 部门/项目组合人力成本趋势；
- 单项目 ROI 跟踪与回款计划；
- 费用异常清单（超支/低使用率）。
