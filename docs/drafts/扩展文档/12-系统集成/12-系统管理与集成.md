# 12 系统管理与第三方集成

## 12.1 基础管理

- **组织管理**：多公司、多部门、虚拟团队；
- **用户与账号**：邀请/激活/停用/合并/移交；支持 AD/LDAP 同步；
- **角色与权限**：自定义角色 + 权限继承/互斥；
- **字典与编码**：项目分类、行业、阶段、币种、地区等；
- **租户管理**：集团-子公司-部门 多级；
- **个性化**：Logo、主题色、登录页、首页布局。

## 12.2 集成架构

- **协议**：RESTful API、GraphQL、Webhook、事件总线（Kafka/ROCKETMQ）、SFTP；
- **鉴权**：OAuth 2.0、OIDC、SAML 2.0、API Key；
- **限流与配额**：每租户/每应用 限流；
- **可观测性**：调用日志、重试、熔断、告警；
- **数据同步**：CDC（基于事件）、定时拉取、推送；
- **沙箱环境**：集成预联调与回归。

## 12.3 关键集成

| 系统 | 集成内容 |
| --- | --- |
| **SSO/IDaaS** | SAML 2.0 / OIDC / LDAP 同步 |
| **OA/审批** | 待办、流程回写、消息中心、待办数 |
| **企业 IM**（企业微信/钉钉/飞书） | 单点登录、消息卡片、应用入口、审批机器人、通讯录 |
| **邮件** | 通知、报表、日历 |
| **研发 ALM** | 需求/缺陷/版本/构建 双向同步 |
| **DevOps** | 流水线/部署/环境/质量门禁 状态回写 |
| **ERP/财务** | 成本归集、采购、合同、付款、汇率 |
| **HR** | 人员、岗位、组织、请假、出勤 |
| **CRM/销售** | 客户、合同、订单、回款 |
| **BI/数仓** | 主数据推送、宽表抽取、指标同步 |
| **电子签** | 合同/交付物签字 |
| **网盘/对象存储** | 文档存储 |
| **日历** | Outlook/Google/Exchange |
| **客服/工单** | 客户报修/请求转项目 |
| **AI 助理** | 智能问答、自动报告、风险预测（详见 §13.10） |

## 12.4 开放能力

- **Open API**：完整 API 文档（OpenAPI 3.0）、SDK（Java/JS/Python）、Postman 集合；
- **Webhook 出站**：事件订阅（项目创建、任务变更、风险升级…）；
- **低代码扩展**：自定义对象、自定义字段、自定义页面（Form/Detail/List）；
- **插件市场**：内置官方插件 + 第三方 + 自研。

## 12.5 审计与合规

- **操作日志**：所有写操作 + 关键读操作；
- **登录日志**：含 IP、UA、地理位置、异常识别；
- **数据变更审计**：字段级前后值；
- **合规导出**：GDPR/等保 数据导出与删除；
- **防篡改**：日志哈希链/区块链存证（可选）。
