# A3 UI/UX 原型 Part1 — 信息架构与组件清单

> 本 Part 覆盖：A3.0 设计原则、A3.1 信息架构（IA）、A3.2 关键页面清单、A3.3 组件库清单。
> Part2 将提供 8 个核心页面的 ASCII Wireframe。

---

## A3.0 设计原则

| 原则 | 说明 |
| --- | --- |
| P1 - 一体化 | 项目空间、任务、文档、风险、工时、消息 单一入口 |
| P2 - 角色化 | 不同角色登录后看到不同的首页与导航（PMO 组合 / PM 项目 / 成员 任务） |
| P3 - 可视化 | 健康度、RAG、燃尽、热力、对比 等数据以图表优先 |
| P4 - 移动优先 | 关键路径 ≤ 3 步，支持离线工时、扫码 @ |
| P5 - 可发现 | 命令面板（Cmd-K）、全文搜索、上下文推荐 |
| P6 - 渐进披露 | 默认信息密度低，高级信息按需展开 |
| P7 - 治理与效率 | 审计/合规视图 与 高效操作视图 分离 |
| P8 - 一致性 | 颜色（红黄绿 RAG）、术语、图标、交互统一 |
| P9 - 可访问性 | WCAG 2.1 AA，键盘可达，屏幕阅读器友好 |
| P10 - 国际化 | 中/英，RTL 预留 |

## A3.4 交互模式（关键）

### A3.4.1 拖拽（Drag & Drop）

- 看板卡片列间拖拽（自动写状态变更 + 触发评论）；
- 甘特条形左右拖拽改期（受日历影响）；
- WBS 节点上下移动改层级；
- 资源矩阵中拖拽人员改占用。

### A3.4.2 命令面板（⌘K）

- 打开：⌘K / Ctrl+K；
- 内容：项目/任务/文档/用户/命令/最近访问；
- 操作：跳转、创建、状态变更、命令执行；
- 模糊匹配 + 历史 + 收藏。

### A3.4.3 批处理

- 多选后悬浮操作栏（更改状态、分配、添加标签、删除、导出）；
- 跨页保存选择（最多 200 条）；
- 异步执行 + 进度 + 结果明细。

### A3.4.4 表单编排

- 字段类型：text/number/select/date/user/ref/file/richtext/formula/signature；
- 字段权限：可见/可编辑/必填 按角色；
- 公式字段：白名单函数（IF/SUM/AVG/CASE/LOOKUP）；
- 校验：必填/正则/范围/跨字段；
- 自动保存（每 5s）与版本对比。

### A3.4.5 在线协作

- WebSocket 推送事件：编辑/评论/状态变更；
- 冲突：last-write-wins（带提示）或乐观锁（带 diff）；
- Presence：当前在线用户头像展示。

### A3.4.6 离线支持（移动端）

- 工时填报、任务查看支持离线；
- 本地 IndexedDB 缓存；
- 上线后自动同步 + 冲突提示。

### A3.4.7 移动端特有

- 下拉刷新、上拉加载；
- 滑动手势（卡片左滑编辑/删除）；
- 拍照/扫码 @任务/资产；
- 推送：本地通知 + 系统通知；
- 适配：iPhone 刘海/底部安全区。
