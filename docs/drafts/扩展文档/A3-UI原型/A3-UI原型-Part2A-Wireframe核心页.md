### 1.4 关键元素说明

| 元素 | 来源 | 更新策略 |
| --- | --- | --- |
| Hero 状态/RAG | projects.health_score / rag | 5s 拉新 + WebSocket |
| 关键指标卡 | SPI/CPI/范围/质量 计算 | 1min 缓存 |
| 里程碑时间线 | milestones 表 | 实时 |
| Sprint 燃尽 | sprints.id → burndown | 实时 |
| 待办（我） | work_items where assignee=me | WebSocket |
| Top 风险 | risks order by score desc limit 5 | 1min |
| 项目动态 | event_outbox 流 | WebSocket（聚合） |
| 最近文档 | documents.last_modified_at desc | 1min |

### 1.5 关键交互

- **Hero RAG 点击**：弹出健康度详情（5 维度雷达图）；
- **里程碑点击**：跳转里程碑详情 + 偏差分析；
- **指标卡悬停**：tooltip 显示计算公式与原始数据；
- **@评论 → 跳转**：点击 Feed 跳转对应对象详情；
- **Tab 切换**：URL hash 同步（`#/project/p-001?tab=risks`）；
- **快捷键**：`g o` 跳概览，`g t` 跳任务，`g r` 跳风险，`g d` 跳文档；
- **保存视图**：右上角"+" → "另存为我的视图"。

### 1.6 响应式断点

| 断点 | 行为 |
| --- | --- |
| ≥ 1440px | 3 列（侧栏 8/24 + 主体 16/24 双卡） |
| 1024-1439 | 2 列（侧栏 6/24 + 主体 18/24） |
| 768-1023 | 1 列，Tab 转为左侧抽屉导航 |
| < 768 | 移动端首页（精简为：状态卡 + 里程碑 + 我的待办） |

### 1.7 可访问性

- 全部指标卡支持键盘 Tab + Enter 触发详情；
- 状态徽章用图标+文字（不仅靠颜色，色盲友好）；
- ARIA：`role="region"`, `aria-label="项目健康度"`；
- 跳到主要内容：⌥+1 / Alt+1。

### 2.4 关键元素说明

| 元素 | 来源 | 备注 |
| --- | --- | --- |
| 列（状态） | work_items.status | 列可配置/新增 |
| WIP 限制 | 列配置 | 超出橙色告警列头 |

### 2.5 关键交互

- **拖拽列间**：触发 `POST /work-items/{id}/transitions`；带评论 + 字段（如指派人变更）；
- **拖拽列内**：纯排序（写 display_order）；
- **点击卡片**：右侧抽屉打开任务详情（不跳页）；
- **快速操作**：卡片右键菜单（编辑/指派/复制链接/转风险/转任务）；
- **批量多选**：按住 Shift / Cmd 多选 → 悬浮操作栏；
- **过滤栏**：按 Sprint/负责人/标签/优先级/类型/截止/自定义字段，保存为视图；
- **泳道切换**：顶部"按 X 分组"下拉（负责人/优先级/标签/Sprint）；
- **WIP 编辑**：列头右键 → 设置 WIP 限制；
- **键盘**：J/K 在卡片间移动；E 编辑；⌘+→ 状态前进；⌘+← 状态回退；
- **命令面板**：⌘K → "切换到列表视图"。

### 2.6 性能与渲染

- 虚拟化：超过 200 张卡片启用虚拟滚动（react-window）；
- WebSocket：状态变更、评论、新增卡片 实时推送；
- 拖拽乐观更新：本地先动，服务失败回滚 + Toast；
- 卡片懒加载：图片/附件缩略图 IntersectionObserver；
- 大量列：横向虚拟化（仅渲染可视列 + buffer）。

### 2.7 状态机

```
BACKLOG → TODO → IN_PROGRESS → IN_REVIEW → DONE
              ↘ BLOCKED ↗        ↘ (驳回) → TODO
                              DONE → ARCHIVED（30 天后）
```

- BACKLOG → TODO：Sprint 计划拖入
- TODO → IN_PROGRESS：领取/拖动
- IN_PROGRESS → BLOCKED：标记阻塞（必填原因）
- BLOCKED → IN_PROGRESS/TODO：解除阻塞
- IN_PROGRESS → IN_REVIEW：提交评审
- IN_REVIEW → DONE/DONE（条件）/TODO（打回）
- DONE → ARCHIVED：自动

### 2.8 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1280 | 显示 5-6 列 + 泳道展开 |
| 768-1279 | 显示 3 列（其余横向滚动）+ 泳道折叠为"查看全部" |
| < 768 | 移动端切到"列表+分组"模式（保留拖拽） |

### 2.9 可访问性

- 卡片：`<article role="listitem">`，含 `aria-label`（标题+负责人+优先级）；
- 列：`<section role="list" aria-label="In Progress">`；
- 拖拽：必须有键盘替代（J/K + Enter 触发菜单）；
- 焦点环明显，色盲模式下色条+文字+图标三重标识。

### 3.5 关键交互

- **拖拽条形左右**：改 start/end（自动重算依赖）；
- **拖拽条形主体**：整体平移；
- **拖拽端点**：仅改 end（工期不变）；
- **连线**：在条形末端按住拖至目标条形 → 创建依赖（弹出 FS/SS/FF/SF + Lag）；
- **右键菜单**：拆分/合并/转任务/添加子项/转风险/查看历史；
- **双击条形**：编辑任务详情（侧滑抽屉）；
- **行高拖拽**：批量调整（多选）；
- **缩放**：日/周/月/季/自定义（Ctrl+滚轮）；
- **基线对比**：双指时间线 → 选 "对比 V2.0/V2.1" → 双条并列；
- **关键路径高亮**：点击 "📅 关键路径" → 全部非关键任务灰化；
- **过滤**：按负责人/标签/状态/部门/资源；
- **键盘**：↑/↓ 选行、←/→ 移动时间、Space 编辑、Del 删除依赖；
- **导入/导出**：MS Project XML、Excel 模板、JSON；
- **基线发布**：菜单"发布为新基线 V2.2" → 走审批。

### 3.6 性能策略

- **虚拟渲染**：仅渲染可视行 + 上下 20 行 buffer；
- **画布技术**：Canvas 2D（≤2k 任务）或 WebGL（>2k 任务）；
- **分块加载**：时间线按月分块，懒加载；
- **Web Worker**：关键路径计算、依赖解析 后台跑；
- **IndexedDB**：本地缓存基线和过滤配置；
- **大数据提示**：>5k 任务时提示"建议切换到资源视图"。

### 3.7 基线对比模式


- 提前 = 绿色对角
- 推迟 = 红色对角
- 范围 = 黄色

### 4.6 关键交互

- **标题内联编辑**：单击直接编辑，自动保存（debounce 1s）；
- **状态机下拉**：受限（按状态机规则 + 权限）；
- **描述富文本**：⌘+B/I、⌘+K 插入链接、/ 触发命令菜单（插入表格/任务块/代码块）；
- **@人**：触发用户搜索 → 发送通知；
- **子任务**：快速添加（回车即创建）；
- **检查清单**：点击勾选 → 实时更新；
- **附件**：拖拽上传 → 进度 → 预览；
- **关联**：点击关联图 → 显示有向图；
- **键盘**：
  - `E` 编辑模式
  - `M` 写评论
  - `A` 指派
  - `L` 加标签
  - `D` 截止日期
  - `⌘+Enter` 发送评论
  - `Esc` 关闭抽屉
- **协作（实时）**：
  - WebSocket 推送：评论、新增子任务、状态变更、编辑
  - 锁字段：富文本按段落锁，显示谁在编辑
  - 冲突：乐观锁 + 提示
- **全屏模式**：`⌘+Shift+F` 或点击 [全屏↗]；
- **复制链接**：URL 携带 deep link（#workitem/wi-203?tab=time）；
- **转对象**：右键 → 转 Bug / 转风险 / 转任务 / 转子项目；
- **历史时间线**：折叠为侧栏（默认关）；
- **AI 助手**：右上角 🤖 → 智能摘要 / 自动拆解 / 风险识别。

### 4.7 抽屉 vs 全屏 模式选择

| 模式 | 触发 | 适用场景 |
| --- | --- | --- |
| **抽屉**（默认） | 从看板/列表点击 | 快速浏览/单点操作 |
| **全屏** | 任务详情按 [全屏] 或 URL `/work-items/{id}` | 深度编辑、复杂任务 |
| **新标签页** | 中键/⌘+点击 | 多任务对比 |

### 4.8 移动端

- 抽屉 → 全屏 Bottom Sheet（圆角 + 拖拽下拉关闭）；
- Tabs 转为顶部 Tab Bar；
- 右侧属性卡 → 折叠为底部"详情"按钮 → 弹出半屏；
- 写评论始终在底部固定；
- 适配 iOS 安全区。

### 4.9 性能

- **懒加载**：评论分页（每页 20 条），子任务按需；
- **虚拟滚动**：子任务 / 历史超过 100 条时启用；
- **WebSocket 节流**：编辑状态 200ms 节流；
- **图片懒加载**：评论中图片 IntersectionObserver；
- **缓存**：上次打开的 Tab、折叠状态 写入 localStorage。

### 4.10 业务规则

- 关闭工作项（DONE）后只能"重新打开"（带理由）；
- 阻塞必须填写 `blocked_reason`，UI 显式提示；
- 移交负责人 → 通知新负责人 → 自动加为关注人；
- 删除（归档）必须二次确认；
- 强回执文档/合规任务 → 必填 `confirmation`。

### 4.11 可访问性

- 抽屉 `<aside role="complementary" aria-label="任务详情">`；
- 状态切换 `<button aria-haspopup="listbox">`；
- 评论支持 Markdown 但渲染为语义化 HTML（h2/h3/ul/ol）；
- 焦点陷阱（Tab 循环在抽屉内）；
- 屏幕阅读器朗读：状态、优先级、负责人、剩余时间。
