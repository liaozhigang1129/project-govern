### 5.4 关键元素说明

| 元素 | 来源 | 备注 |
| --- | --- | --- |
| 投资分布 | projects.total_budget group by BU | 双图（饼+柱） |
| 战略地图 | projects + strategic_priority | 散点（收益 × 风险） |
| RAG 列表 | projects.rag/rollup | 实时 |
| Top 风险 | risks order by score | 实时 |
| 收益跟踪 | projects.actual_roi vs expected | T+1 |
| KPI 卡条 | 聚合计算 | 5s 缓存 |

### 5.5 关键交互

- **KPI 卡点击**：下钻到详情（如"投资" → 投资明细）；
- **饼图/柱图扇区**：下钻到列表（按 BU/类型 过滤的项目列表）；
- **战略地图气泡**：点击 → 项目详情，气泡大小=预算；
- **RAG 列表**：列排序、过滤、跳转项目空间；
- **风险点击**：跳转风险详情 + 应对措施；
- **时间筛选**：本季度/本年度/自定义；
- **BU 筛选**：单选/多选/含子部门；
- **订阅**：邮件/IM 推送 + 频率（每日/每周）；
- **分享**：生成只读链接（含水印）+ 权限继承；
- **命令面板**：`⌘K` 跳项目/风险/报表；
- **全屏模式**：F11 → 隐藏导航 + 大屏适配；
- **自定义**：拖拽组件，保存为个人/角色仪表盘。

### 5.6 性能

- **多源聚合**：CQRS 视图（项目汇总表）+ ClickHouse/StarRocks；
- **5s 缓存 + 实时刷新**（关键指标）；
- **大数据渲染**：列表 1k 行虚拟滚动 + 列冻结；
- **图表懒加载**：滚动到可视区再渲染；
- **预聚合**：每日凌晨刷新战略地图、投资分布等。

### 5.7 仪表盘订阅

```
┌─ 订阅设置 ─────────────────────────────────────┐
│ 频率: [每周一 9:00▾]                          │
│ 格式: ☑ PDF  ☑ 链接  ☐ Excel                  │
│ 渠道: ☑ Email  ☑ IM  ☐ SMS                    │
│ 收件人: 张总监、李总、PMO 经理                 │
│ 水印: ☑ 收件人邮箱                             │
│ [保存] [测试发送] [取消]                        │
└────────────────────────────────────────────────┘
```

### 5.8 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1920 | 4-5 列 KPI + 双图并排 + 列表 + 风险 + 收益 |
| 1440-1919 | 4 列 KPI + 双图并排 + 列表（占比大） |
| 1024-1439 | 2 列 KPI + 单图 + 列表全宽 |
| 768-1023 | 1 列布局，图表转卡片 |
| < 768 | 移动端摘要视图（KPI + Top 5 风险） |

### 5.9 可访问性

- KPI 卡 `<button role="button" aria-label="投资 ¥1.2亿 同比+12%">`；
- 图表有同义数据表（按 Tab 切换"图表/数据"）；
- 颜色编码同时用图标（↑↓）和文字；
- 屏幕阅读器朗读：当前时间范围 + 各 KPI 数值 + 趋势。

### 5.10 业务规则

- 仪表盘数据权限 = 角色 + 数据域（PMO 总监看全部，部门 PMO 经理看本部门）；
- 战略地图坐标轴 0-100 标准化；
- 风险等级阈值可按组合配置；
- 投资额按项目主币种 + 实时汇率换算；
- 导出 PDF 含水印、页眉/页脚（保密标识 + 时间戳）。

### 6.5 视图模式

| 视图 | 块大小 | 含义 |
| --- | --- | --- |
| 占用率 | 高度 | 数值 0-150% |
| 工时 | 高度 | h 数 |
| 热力 | 颜色 | 阈值映射 |
| 冲突 | 颜色 | 🔴=冲突 🟡=接近上限 🟢=正常 |

### 6.6 关键交互

- **拖拽项目块改期**：在 W 上拖动改 start/end（自动校验冲突）；
- **拖拽到人员**：把项目分配给其他人（弹出确认 + 影响分析）；
- **点击项目块**：右侧抽屉显示资源详情（费率/时间/任务）；
- **右键**：拆分/合并/移交/释放/查看历史；
- **平衡建议**：⚖ 按钮 → 列出可移动/释放的分配，含相似度推荐；
- **冲突告警**：点击冲突项 → 跳转冲突详情（重叠周次、合计占用率、推荐方案）；
- **过滤**：技能/角色/部门/可用性/合同类型；
- **快速操作**：选中多人 → 批量调整/批量释放/批量审批；
- **键盘**：↑/↓ 选人、←/→ 选周、Space 编辑、Del 释放；
- **未来预测**：切换到 8 周未来视图（虚线=预测）。

### 6.7 性能

- **大数据**：500+ 人员时启用虚拟滚动；
- **预聚合**：每日凌晨计算"未来 12 周利用率"；
- **Web Worker**：冲突检测、相似度推荐 后台跑；
- **Canvas 渲染**：500+ 人员×52 周 网格 → Canvas 2D；
- **本地缓存**：过滤条件、视图模式 写入 localStorage。

### 6.8 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1440 | 双栏（人员 240 + 矩阵 fluid） |
| 1024-1439 | 人员树 180 + 矩阵 |
| 768-1023 | 单列，矩阵转横向滚动 |
| < 768 | 移动端用"人员详情 + 时间线"替代 |

### 6.9 可访问性

- 占用块 `<button aria-label="张三 智能客服V2 4/1-4/15 占用 100%">`；
- 冲突不仅靠颜色：块加红边 + 角标 + Toast；
- 键盘可达：Tab 跳人员/项目块，回车编辑；
- 屏幕阅读器朗读：人员/项目/占用率/状态。

### 6.10 业务规则

- 占用率 > 100% = 冲突（红色），90-100% = 警告（黄色）；
- 关键人：被 ≥ 2 个 P0 项目依赖 + 不可替代（无相似度 ≥ 0.8 候选）；
- 释放：必须先释放现有分配或被新项目替代；
- 平衡建议：基于技能相似度（标签 + 等级 + 历史项目）；
- 即将到期提前 14 天提醒；
- 离职/转岗：触发"项目交接"工作流，列出受影响项目 + 备选人。

### 6.11 移动端

- 人员列表（卡片：姓名 + 当前项目 + 利用率 + 冲突标）；
- 详情页：当前/历史项目时间线；
- 快速操作：调整/释放/发起交接。

### 7.5 视图模式

#### 矩阵视图（默认）

- 5×5 网格，气泡=数量；
- 鼠标悬浮单元 → 显示该单元风险列表 tooltip；
- 点击单元 → 下方列表过滤；
- 拖拽气泡：移动即调整 P/I（仅 own risks 可改）。

#### 时间趋势视图

- 折线：每周新增/关闭/升级 数量；
- 堆积柱：每周各等级新增；
- 区域图：风险总值随时间变化；
- 时间窗选择：4 周/12 周/年度/自定义。

#### 列表视图

- 全列表（多列、可排序、可过滤、可分组）；
- 与矩阵视图共享过滤条件。

### 7.6 关键交互

- **气泡点击**：下钻风险列表（自动过滤该单元）；
- **气泡拖拽**：调整 P/I（需 own 或 PM 权限，触发 `reassess` API）；
- **悬浮**：tooltip 显示单元详情（数量、升级中、关键风险 3 条）；
- **升级按钮**：⚠ → 弹出升级对话框（选人、填理由、走流程）；
- **导出**：CSV / Excel / PDF（含矩阵图）；
- **订阅**：每周/每月风险摘要推送；
- **过滤**：类别/项目/状态/owner/标签；
- **时间窗**：4/12/52 周/自定义；
- **键盘**：Tab 跳气泡、回车打开、Esc 关闭；
- **联动**：点击列表行 → 矩阵中对应气泡高亮闪烁。

### 7.7 性能

- **大数据**：1000+ 风险时，气泡聚合预计算（每日凌晨 + 实时增量）；
- **Canvas 渲染**：气泡、连线、动画；
- **WebSocket**：新增/关闭/升级 实时推送，矩阵数字实时更新；
- **CDN 缓存**：阈值、图例、静态资源；
- **虚拟滚动**：列表 1k+ 行时启用。

- 矩阵 `<table role="grid" aria-label="风险概率影响矩阵">`；

- 颜色+图标+文字三重标识（色盲友好）；
- 列表 ARIA：`<table role="table" aria-rowcount>`。

### 7.10 业务规则

- **P/I 等级**：1-5；
- **score = P × I**，范围 1-25；
- **等级阈值**（可按组合配置）：
  - EXTREME: 15+
  - HIGH: 10-14
  - MEDIUM: 5-9
  - LOW: 1-4
- **升级策略**：
  - EXTREME 立即升级至 PMO 总监
  - HIGH 升级至部门 PMO 经理
  - 复评到期未评 → 自动升级
- **事件化**：risk.materialize = 实际发生 → 转 Issue；
- **闭环**：closed 状态 + 关闭时间 + 关闭原因；
- **经验沉淀**：关闭时强制填写 lessons_learned；
- **历史回溯**：每次 P/I 调整留痕（risk_reviews）。

### 7.11 移动端

- 风险卡片列表（按等级排序）；
- 卡片：等级 + 标题 + 项目 + 责任人 + 状态 + 操作；
- 详情页：完整字段 + 应对措施 + 历史；
- 快速操作：升级 / 复评 / 关闭。

### 8.8 离线策略

| 状态 | 行为 |
| --- | --- |

### 8.12 业务规则

- **每日上限**：工作 12h，加班 4h，总计 16h（软限，超 12h 提示 + 主管确认）；
- **每周目标**：40h（可按部门配置）；
- **跨日提交**：不允许跨周修改已提交工时（需解锁审批）；
- **类型切换**：工作 → 加班 = 增加预算占用；请假 = 释放产能；
- **工时必填项**：项目 + 任务 + 时长 + 描述（≥ 5 字符）；
- **批量提交**：超过 3 项需复核；
- **逾期提醒**：每周一 9:00 推送未填提醒；
- **强制回执**：月底 / 季底 / 项目结束前 100% 填齐才允许签字。

### 8.13 隐私与安全

- 截屏禁用（敏感项目可配置）；
- 移动设备绑定（首次激活 + 二次确认）；
- 远程擦除（离职/丢失时）；
- VPN / 零信任网络访问；
- 拍照附件不保留本地副本（仅上传）；
- 定位数据可选，开启需用户授权。
