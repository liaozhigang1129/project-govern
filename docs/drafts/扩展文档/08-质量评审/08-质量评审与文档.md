# 8 质量、评审、文档与交付物管理

## 8.1 评审管理

| 编号 | 需求描述 |
| --- | --- |
| FR-8.1-01 | 评审类型：立项评审、阶段评审（Stage Gate）、技术评审、设计评审、验收评审、结项评审 |
| FR-8.1-02 | 评审单字段：项目/阶段、评审类型、评审时间、评审材料（清单）、评审委员、评审标准、结论（通过/有条件通过/打回/取消） |
| FR-8.1-03 | 评审**材料自动归集**：从文档库、代码库、ALM 拉取 |
| FR-8.1-04 | 评审**打分卡**（多维度）、**反对意见**强制留痕 |
| FR-8.1-05 | 评审**行动项（Action Items）** 转任务跟踪 |
| FR-8.1-06 | 评审结论与**阶段门**强制绑定 |

## 8.2 文档管理

| 编号 | 需求描述 |
| --- | --- |
| FR-8.2-01 | **多级目录**（项目/阶段/类别） |
| FR-8.2-02 | 文档类型：需求、设计、计划、报告、会议纪要、合同、模板、规范 |
| FR-8.2-03 | **版本控制**：主版本.次版本，自动与手动签入 |
| FR-8.2-04 | **检入/检出** 与 **并发编辑冲突** 处理 |
| FR-8.2-05 | **审批发布**：草稿 → 审核 → 发布 → 归档 |
| FR-8.2-06 | **模板库**：按文档类型与行业 |
| FR-8.2-07 | **阅读回执**：重要文档要求确认阅读 |
| FR-8.2-08 | **知识库（KB）**：跨项目知识沉淀、全文检索、智能推荐 |
| FR-8.2-09 | **水印、防下载、加密**（按密级） |
| FR-8.2-10 | 与企业网盘/对象存储集成 |

## 8.3 交付物管理

- **交付物清单（DDP, Deliverable Definition Package）** 与 WBS 节点绑定；
- 交付物状态：未开始/编制中/送审/已批准/已交付/已验收；
- **交付物验收单**：SOW/规格/数量/时间窗/验收人/意见；
- 阶段交付物（Stage Gate Deliverable）强制清单；
- 客户**签字/电子签**（集成电子签章服务）。

## 8.4 质量管理

- **质量计划**：质量目标、度量指标、评审与测试策略；
- **质量度量**：缺陷密度、逃逸率、SLA 达成率、评审一次通过率、按时交付率；
- **质量审计**：PMO 质量角色按计划审计、生成审计报告；
- **持续改进（CI）**：基于度量与审计的改进行动。
