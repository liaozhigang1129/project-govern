# 14 数据模型与接口规范

## 14.1 关键实体（核心域模型）

> 命名风格：领域驱动（聚合根用复数）。以下为**核心实体清单**，详细字段在《数据字典》中维护。

### 14.1.1 项目域

- **Project**（聚合根）
  - id, code, name, type, category, level, secretLevel, status
  - sponsorId, pmId, deptId, businessUnitId
  - startDate, endDate, baselineId
  - healthScore, ragStatus
  - portfolioId, programId
- **Program**（项目集）
- **Portfolio**（项目组合）
- **WbsNode**（工作分解节点）
- **Milestone**（里程碑）
- **Baseline**（基线版本）
- **StageGate**（阶段门）
- **ProjectMember**（项目成员 + 角色）
- **ProjectTemplate**（项目模板）

### 14.1.2 工作项域

- **WorkItem**（统一工作项，type=Epic/Feature/Story/Task/Bug）
  - id, key, type, title, status, priority, severity
  - projectId, sprintId, parentId
  - assigneeId, reporterId, watchers
  - estimate, actual, remaining
  - startDate, dueDate, doneDate
  - labels, customFields
- **Sprint**（迭代）
- **Backlog**
- **Dependency**（依赖）
- **Comment**
- **Attachment**

### 14.1.3 资源域

- **User**
- **Department**
- **Skill**, **SkillLevel**, **Certification**
- **ResourcePool**
- **ResourceAssignment**（预占/确认/释放）
- **Calendar**, **Holiday**, **Leave**

### 14.1.4 成本域

- **Budget**（项目/阶段/WBS 多层级）
- **BudgetVersion**
- **TimeEntry**（工时单）
- **Expense**（报销）
- **Procurement**（PR/PO/合同）
- **CostActual**（来自 ERP）

### 14.1.5 风险/质量域

- **Risk**
- **Issue**
- **Defect**（可与 ALM 双向同步）
- **ChangeRequest**
- **Review**（评审）
- **ActionItem**
- **AuditLog**

### 14.1.6 交付与文档

- **Deliverable**
- **Document**, **DocumentVersion**
- **Knowledge**（知识库条目）

### 14.1.7 流程与通知

- **Workflow**（流程定义）
- **WorkflowInstance**（流程实例）
- **Notification**

## 14.2 实体关系（简图）

```
Portfolio 1—N Program 1—N Project 1—N WbsNode 1—N WorkItem
Project 1—N Milestone / Risk / Issue / ChangeRequest / Deliverable / Document / Review
Project 1—N Budget — N BudgetVersion
Project 1—N ResourceAssignment N—1 User

WorkItem 1—N Comment
Sprint 1—N WorkItem

```

## 14.3 关键接口规范

### 14.3.1 RESTful 规范

- 资源命名：复数名词（`/projects`, `/projects/{id}/tasks`）；
- HTTP 语义：GET/POST/PUT/PATCH/DELETE；
- 分页：`?page=1&size=20&sort=field,asc` 或 cursor；
- 过滤/搜索：`?filter[field]=value&search=keyword`；
- 字段投影：`?fields=id,name,status`；
- 错误：`{ code, message, traceId, details }`，符合 RFC 7807；
- 版本：URL `/v1/...` 或 Header `Accept-Version: 1.0`。

### 14.3.2 鉴权

- `Authorization: Bearer <JWT>`，JWT 含 `sub`, `tenant`, `roles`, `scopes`；
- OAuth 2.0：`client_credentials`、`authorization_code`；
- 内部服务互调用：mTLS + ServiceAccount Token。

### 14.3.3 事件规范（Webhook/Event Bus）

```json
{
  "eventId": "uuid",
  "eventType": "project.task.updated",
  "occurredAt": "2025-01-01T08:00:00Z",
  "tenantId": "t-001",
  "producer": "pmo-pms",
  "data": { "...": "..." },
  "version": 1
}
```

- 事件类型清单（节选）：
  - `project.created` / `project.status_changed`
  - `project.baseline.published`
  - `workitem.created` / `workitem.updated` / `workitem.status_changed`
  - `risk.opened` / `risk.escalated` / `risk.closed`
  - `change.approved` / `change.rejected`
  - `budget.exceeded`
  - `review.completed`
  - `workflow.completed`
  - `resource.conflict.detected`

### 14.3.4 限流

- 默认 60 req/min/user，租户级 10,000 req/min；
- 超限返回 `429` + `Retry-After`。

## 14.4 主数据治理

- **数据所有者**：Project、WorkItem、User、Department；
- **黄金记录**：客户、供应商、币种、汇率；
- **编码规则**：可配置 + 唯一性；
- **同步策略**：以 PMS 为源，ERP/ALM 为消费方；
- **数据脱敏**：API 默认脱敏，按角色解密。
