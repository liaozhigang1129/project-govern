# 15 验收标准、试点与上线

## 15.1 验收层次

| 层次 | 责任方 | 内容 |
| --- | --- | --- |
| 单元测试 | 研发 | 代码覆盖、功能正确 |
| 集成测试 | 研发 + QA | 模块间、API、事件 |
| 系统测试 | QA | 全功能 + NFR |
| 用户验收测试（UAT） | 业务方 + PMO | 业务场景、UAT 用例、回归 |
| 性能/安全/合规测试 | 第三方/安全团队 | 渗透、等保、性能压测 |
| 试点验收 | 选定 BU/部门 | 真实环境使用、达成度评估 |

## 15.2 UAT 关键用例（示例）

- 立项 → 计划 → 任务 → 工时 → 成本 → 风险 → 变更 → 结项 端到端；
- 多项目跨依赖；
- 资源冲突与替换；
- 大体量（10 万任务）看板/甘特流畅度；
- 移动端在 4G/弱网下提交工时与审批；
- SSO、字段权限、敏感数据脱敏；
- 流程引擎：会签、加签、转签、超时升级；
- 集成场景：与 OA/IM/ERP/ALM 的关键事件流；
- 离线/恢复/灾备切换演练。

## 15.3 验收标准（Acceptance Criteria）

- **功能完成度**：SRS 中标注的 P0 功能 100% 通过、P1 ≥ 95% 通过；
- **缺陷率**：遗留 P1 缺陷 0、P2 ≤ 总用例 1%；
- **NFR**：性能、可用性、安全指标全部达标；
- **合规**：等保测评通过、隐私影响评估通过；
- **文档**：用户手册、管理员手册、运维手册、API 文档齐备；
- **培训**：完成关键用户/管理员培训并通过考核。

## 15.4 试点计划

- **试点范围**：选 1-2 个 BU 或 1-2 个项目集，覆盖核心角色；
- **周期**：6-8 周（其中 2 周试运行 + 4-6 周数据迁移与培训）；
- **关键指标**：立项覆盖率、计划完成率、用户活跃度、采纳率；
- **Go/No-Go 评审**：试点结束形成 Go/No-Go 决议。

## 15.5 上线

- **数据迁移**：模板 + 历史项目 + 文档 + 工时；
- **割接策略**：灰度切流（金丝雀 → 50% → 100%），出现问题回退；
- **上线支持**：7×24 现场/远程保障两周；
- **回退预案**：数据快照、应用版本回滚、用户无感切换。

## 15.6 培训与变更管理

- 用户分层培训：管理员/PM/成员/业务方；
- 培训方式：现场+在线+视频库+认证；
- 沟通计划：上线前 30/15/7/1 天 + 上线 D-Day 节奏；
- **变更代理网络（Champions）**：每个 BU 培养内部讲师/推广者。

## 15.7 运维与持续改进

- 监控、告警、值班、应急响应；
- 季度回顾：使用率、KPI、用户反馈、Roadmap 调整；
- 持续交付：双周迭代、Feature Flag、A/B 测试。
