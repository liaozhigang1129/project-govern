# 10 报表、仪表盘与数据分析

## 10.1 角色化仪表盘

| 角色 | 仪表盘内容 |
| --- | --- |
| PMO 总监 | 组合全景、投资分布、RAG、战略地图、KPI 达成率、Top 风险 |
| PMO 经理 | 项目集健康度、阶段审计、PM 排名、资源热点 |
| 项目经理（PM） | 我的项目、待办、风险、里程碑、Sprint 燃尽、团队利用率 |
| 部门负责人 | 部门资源利用率、部门项目 RAG、关键人风险 |
| 资源经理 | 资源冲突、未来 4 周空缺、人员空档 |
| 业务负责人 | 收益达成、ROI、关键里程碑、变更概览 |
| 财务 | 预算 vs 实际、应收应付、合同回款 |
| 任务执行人 | 我的任务、Sprint、待填工时、被@/评论 |
| 审计 | 操作日志、变更日志、敏感数据访问 |

## 10.2 报表类型

- **状态报告**：周/月/季度；
- **挣值报告（EVM）**：PV/EV/AC/SPI/CPI/TCPI/EAC/VAC；
- **资源报表**：利用率热力、人员借调、未来可用；
- **风险热力**：P×I 矩阵 + 时间维度；
- **质量报表**：缺陷密度、SLA、评审一次通过率；
- **预算/成本报表**：多维（项目/部门/WBS/类别/期间）预算 vs 实际；
- **组合报表**：投资、收益、战略对齐；
- **人员绩效**：项目参与度、任务完成率、工时合规（脱敏）；
- **审计合规报表**：操作日志、登录、敏感数据访问。

## 10.3 自助分析（BI）

- **可视化配置**：拖拽式（柱/线/饼/散点/桑基/漏斗/甘特/热力）；
- **维度/度量**：预置业务语义层（如"项目健康度"、"资源利用率"）；
- **筛选/钻取/联动**；
- **报表权限**继承数据权限；
- **订阅与分发**：定时邮件、IM 推送、链接分享（含水印）；
- **导出**：PDF/Excel/CSV/PNG；
- **嵌入式分析**：可嵌入第三方 BI 仪表盘（Tableau/Power BI/帆软等）。

## 10.4 数据质量

- 关键字段**必填与格式校验**；
- 异常检测：超时未更新、孤儿任务、超载人员；
- **数据治理看板**：完整率、准确率、时效性。
