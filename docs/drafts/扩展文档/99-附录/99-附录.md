## 99.5 假设、依赖与约束

### 假设

- 组织有明确的 PMO 治理与项目分级制度；
- 关键干系人/业务部门参与需求评审与 UAT；
- 提供测试与生产环境，IT 提供基础资源；
- 与 OA/IM/ERP/ALM 等系统的接口方配合接口对接。

### 依赖

- 企业 IDaaS / SSO 提供方支持 SAML/OIDC；
- ERP 财务模块提供成本/预算/合同 API；
- ALM 提供 Webhook 与 REST API；
- 企业 IM 提供机器人与卡片能力。

### 约束

- 数据中心区域与跨境合规约束；
- 国产化要求（信创）范围与时间窗；
- 预算与采购流程遵循集团既有制度。

## 99.6 风险与缓解

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| 业务方采纳率低 | 系统空转 | 试点先行 + 变更代理 + KPI 挂钩 |
| 集成复杂度高 | 进度延期 | 接口适配层 + Mock + 早期联调 |
| 数据迁移质量差 | 历史数据失真 | 多次演练 + 校验脚本 + 灰度 |
| 性能不达标 | 用户体验差 | 早期压测 + 容量规划 + 慢 SQL 治理 |
| 角色权限错配 | 数据泄漏 | 渗透测试 + 越权扫描 + 审计 |
| 范围蔓延 | 延期/超预算 | MoSCoW 优先级 + 变更控制 + 季度回顾 |
