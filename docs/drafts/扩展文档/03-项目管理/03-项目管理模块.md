# 3 项目管理核心模块

## 3.1 项目立项与立项书

### 3.1.1 业务描述

通过**结构化立项书模板**统一项目入口，覆盖战略对齐、范围、目标、干系人、风险初识、资源与预算初稿。

### 3.1.2 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-3.1-01 | 支持多套**立项模板**（研发、基建、市场、合规、咨询等），模板可版本化与锁定 |
| FR-3.1-02 | 立项书字段含：项目名称/编号、分类、密级、业务背景、目标/可衡量收益、范围 In/Out、干系人 Raci、关键里程碑初稿、预算初稿、风险初识、ROI 评估、决策人 |
| FR-3.1-03 | 支持**在线编辑 + 多人协同**（段落级锁） |
| FR-3.1-04 | 立项书必须满足**强制校验**（如预算不能为空、目标必须 SMART、ROI 公式） |
| FR-3.1-05 | 立项流程：申请人 → 部门负责人 → PMO 经理复核 → 业务负责人 / PMO 总监 → **立项委员会评审（可选）** → 批准/驳回/打回 |
| FR-3.1-06 | 立项通过后**自动生成项目编号**、初始化项目空间、创建默认结构（计划/任务/文档/风险/预算） |
| FR-3.1-07 | 立项不通过时支持**回退原因**记录与归档 |
| FR-3.1-08 | 支持**从外部**（如 Excel 模板、需求工单、销售合同）触发立项草稿 |

### 3.1.3 业务规则

- 同一业务单元下项目名称+年度内**唯一**；
- 立项编号规则可配置（如 `PRJ-{BU}-{YY}-{SEQ}`）；
- 未通过立项的项目不允许创建任务/工时/资源申请。

## 3.2 项目计划（WBS、里程碑、甘特）

### 3.2.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-3.2-01 | 支持**多级 WBS**（建议 5 级），可从模板复制/从其他项目导入/从 Excel 导入 |
| FR-3.2-02 | 里程碑（Milestone）类型：启动、阶段评审、关键交付、验收、结项 |
| FR-3.2-03 | 甘特图支持：层级折叠/展开、拖拽改期、关键路径高亮、依赖线（前导/后继 FS/SS/FF/SF） |
| FR-3.2-04 | 支持**基线（Baseline）**：可保存多个版本、可对比（差异图）、可回滚 |
| FR-3.2-05 | 资源/工时在 WBS 节点上可视化（柱状热力） |
| FR-3.2-06 | 计划**审批**（基线审批）：PM 提交 → PMO 经理 → 业务负责人 |
| FR-3.2-07 | 与日历联动：自动跳过节假日与休息日 |
| FR-3.2-08 | 计划版本与项目阶段/PMO 阶段评审挂钩 |
| FR-3.2-09 | 支持**敏捷模板**：史诗 Epic → 特性 Feature → 用户故事 Story → 任务 Task |
| FR-3.2-10 | 计划与任务/工时/预算/风险**双向联动**：修改计划自动建议任务调整 |

## 3.3 进度跟踪与基线

### 3.3.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-3.3-01 | 进度数据来源：①任务自动汇总 ②里程碑勾选 ③人工更新（权重） |
| FR-3.3-02 | **EVM 挣值管理**：PV/EV/AC、SPI/CPI/SV/CV、TCPI、VAC、EAC |
| FR-3.3-03 | 进度**RAG 状态**：自动判定 + 人工覆盖（带理由） |
| FR-3.3-04 | **里程碑偏差预警**：阈值可配，触发通知与升级 |
| FR-3.3-05 | 项目**健康度评分卡**：进度/成本/范围/风险/质量/资源 综合 |
| FR-3.3-06 | **自动状态报告**：周报/月报按模板生成，邮件/IM 推送 |
| FR-3.3-07 | **进度偏差大**时强制要求 PM 填写原因与应对措施（≥ 阈值） |
| FR-3.3-08 | 进度与**项目阶段门（Gate）**绑定，未通过不允许进入下一阶段 |
| FR-3.3-09 | 支持**燃尽/燃尽图**（敏捷视角） |

## 3.4 项目变更管理

### 3.4.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-3.4-01 | 变更类型：范围/进度/成本/资源/质量/基线/合同 |
| FR-3.4-02 | 变更申请：申请人、变更描述、原因、影响分析（必填：范围/进度/成本/资源/风险/质量） |
| FR-3.4-03 | **影响分析工具**：自动根据 WBS、预算、资源池估算偏差 |
| FR-3.4-04 | 变更评审：**CCB（变更控制委员会）** 流程，按变更等级（Minor/Major/Critical）走不同审批链 |
| FR-3.4-05 | 变更批准后**自动更新基线**并通知干系人 |
| FR-3.4-06 | 变更日志（Audit Trail）不可篡改，支持回溯 |
| FR-3.4-07 | 紧急变更（Hotfix/EC）走快速通道，事后补走正式变更 |
| FR-3.4-08 | 变更与合同/采购/工时单据**联动**（如预算变更触发 PO 调整） |

## 3.5 项目结项与复盘

### 3.5.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-3.5-01 | 结项条件校验：交付物齐备、预算已结、风险已关闭或转移、文档归档 |
| FR-3.5-02 | **结项报告**模板：目标达成、范围偏差、进度偏差、成本偏差、经验教训、最佳实践、收益后评估 |
| FR-3.5-03 | **复盘会议（Retrospective）**：开始-停止-继续（Start/Stop/Continue）+ 投票 |
| FR-3.5-04 | **经验教训库（Lessons Learned）**：分类/标签/检索/引用 |
| FR-3.5-05 | 项目**档案归档**（合同、文档、代码、资产），可读权限按生命周期自动调整 |
| FR-3.5-06 | **收益后评估**（Post-Implementation Review，PIR）可与业务目标 KPI 关联 |
| FR-3.5-07 | 结项后**资源释放/转场**自动通知资源经理 |

## 3.6 项目集（Program）与项目组合（Portfolio）

### 3.6.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-3.6-01 | **Program**：聚合多个相关项目，共享战略目标/资源池/治理规则 |

| FR-3.6-06 | 组合级**容量规划**：投资上限 vs 实际占用 |
| FR-3.6-07 | 组合级**季度/年度回顾**模板与流程 |
| FR-3.6-08 | 组合级**资金与预算占位**审批 |
