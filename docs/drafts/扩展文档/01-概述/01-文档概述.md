# 1 文档概述

## 1.1 项目背景与问题陈述

随着公司业务规模与项目数量的持续增长，**项目分散在 Excel、邮件、即时通讯与多套工具中**所带来的问题日益突出：

- 立项随意，缺乏统一的项目分级、分类与立项审批；
- 计划/进度不透明，**关键里程碑、责任人、风险无法实时掌握**；
- 资源（人/预算/设备）无统一视图，**忙闲不均与冲突频发**；
- 工时、成本、质量、风险数据**事后补录**，失去管理价值；
- 流程在 OA、研发管理、CRM、ERP 之间割裂，**审批流断点多、追溯难**；
- 管理层缺少**项目组合（Portfolio）视角**和决策依据。

PMO-PMS 系统旨在以"项目"为中心，建设**端到端、可度量、可治理**的项目管理一体化平台，承接 PMO 治理与项目执行两条主线。

## 1.2 建设目标与价值

### 1.2.1 业务目标

| 目标编号 | 描述 | 衡量指标（KPI） |
| --- | --- | --- |
| G1 | 项目全生命周期线上化管理 | 立项覆盖率 ≥ 95%；结项归档率 ≥ 90% |
| G2 | 进度可视可预警 | 关键里程碑准时率 ≥ 80%；红灯项目提前 ≥ 5 天预警 |
| G3 | 资源调度透明高效 | 资源冲突率下降 ≥ 50%；资源利用率可视化覆盖 100% 关键角色 |
| G4 | 工时/成本真实反映 | 工时按时填报率 ≥ 90%；预算偏差 ≤ ±10% |
| G5 | 风险问题闭环 | 风险闭环率 ≥ 95%；高风险项 24h 内响应 |
| G6 | 数据驱动决策 | 管理层组合视图 T+1 可用；自定义报表自助率 ≥ 70% |

### 1.2.2 价值主张

- **PMO**：获得组合（Portfolio）全景，治理与审计可视化；
- **项目经理**：统一协作空间，进度/资源/风险/工时一体化管理；
- **项目成员**：任务清晰、入口统一、消息聚合；
- **业务/财务/质量**：按角色获取数据与流程入口；
- **管理层**：决策仪表盘 + 主动预警。

## 1.3 范围

### 1.3.1 In-Scope

- 项目立项、计划、进度、变更、结项的全生命周期管理；
- 任务与工作项的多视图协作（看板、列表、甘特、迭代）；
- 资源池、人力调度、产能与日历；
- 预算、成本、工时、报销与采购协同；
- 风险、问题、变更、缺陷（可与研发 ALM/工单系统集成，亦提供内置简版）；
- 质量、评审、文档、交付物与版本；
- 通知、评论、@、订阅、消息中心；
- 报表与仪表盘（项目、PMO、资源、财务、组合视图）；
- 审批工作流引擎（可视化配置）；
- SSO、组织/角色/权限/审计；
- 与 OA、IM、邮箱、研发管理（DevOps/ALM）、ERP/财务、BI 等的集成；
- Web 端 + 移动端（iOS/Android）+ 桌面/IM 插件。

### 1.3.2 Out-of-Scope（非本期）

- 项目财务结算总账与税务处理（由 ERP 承担）；
- 复杂的研发 CI/CD 流水线（仅集成与轻量编排）；
- CRM/销售线索全流程（仅项目客户视图）；
- 资产/物料的实物仓储管理（仅审批与台账视图）；
- BIM/PLM 等专业工程系统（仅提供数据回写与链接）。
