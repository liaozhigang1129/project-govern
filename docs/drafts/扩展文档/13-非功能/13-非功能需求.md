# 13 非功能需求（NFR）

## 13.1 性能

| 指标 | 要求 |
| --- | --- |
| Web 首屏 TTFB | ≤ 300 ms（内网）、≤ 800 ms（公网） |
| 页面交互响应 | P95 ≤ 1 s，P99 ≤ 2 s |
| API 平均响应 | P95 ≤ 500 ms（含 DB） |
| 列表分页 | 100 万级数据 P95 ≤ 1.5 s |
| 搜索（全文/结构化） | P95 ≤ 1 s，5 亿级文档 |
| 报表渲染（标准） | 1 万行 ≤ 2 s，10 万行 ≤ 10 s |
| 并发用户 | 5,000 活跃 / 20,000 注册（首期） |
| 写吞吐 | 业务高峰 2,000 TPS，峰值 5,000 TPS |

## 13.2 可用性

- **SLA**：≥ 99.95%（年度停机 ≤ 4.38 小时）；
- **故障恢复 RTO ≤ 30 分钟，RPO ≤ 5 分钟**；
- **多活**：同城双活 + 异地灾备；
- **灰度发布**、**回滚**、**流量录制回放**。

## 13.3 容量与扩展

- 租户：≥ 1,000；
- 项目：≥ 100,000（活跃 10,000）；
- 任务/工作项：≥ 1 亿；
- 文档：≥ 10 亿文件，PB 级；
- 水平扩展：Kubernetes 容器化，无状态服务；
- 数据库：分库分表 + 读写分离；冷热分层（OSS 归档）。

## 13.4 安全

- **认证**：密码 + MFA（短信/TOTP/FIDO2）、SSO；
- **授权**：RBAC + ABAC（如"只能看本部门 + 已分配项目"）；
- **传输**：TLS 1.2+ 全站 HTTPS，HSTS；
- **存储**：敏感字段加密（AES-256/SM4）、KMS 密钥；
- **数据脱敏**：手机号/身份证/银行账户 按角色脱敏；
- **注入防护**：SQL/NoSQL/命令/LDAP 注入；
- **XSS/CSRF**：前端框架 + 严格 CSP + Token；
- **越权防护**：所有 API 服务端二次校验；
- **文件上传**：类型白名单 + 病毒扫描；
- **安全审计**：登录、操作、敏感访问 全留痕；
- **渗透测试**：每季度第三方渗透 + 漏洞修复 SLA。

## 13.5 合规

- **等保 2.0**：三级（生产）、二级（测试）；
- **GDPR/个人信息保护法**：数据出境、最小化、被遗忘权；
- **行业合规**：SOX、ISO 9001、ISO 27001（按需）；
- **日志保留**：≥ 6 年（按行业法规）。

## 13.6 可维护性

- **代码规范**、**单元测试覆盖率 ≥ 70%**、关键链路 ≥ 90%；
- **CI/CD**：自动构建、灰度、滚动升级；
- **可观测性**：指标（Prometheus）、日志（ELK/EFK）、链路（OpenTelemetry）；
- **告警分级**：P0/P1/P2/P3 与值班响应时间挂钩。

## 13.7 可移植性

- **浏览器**：Chrome/Edge/Safari/Firefox 最新两个大版本；
- **移动端**：iOS 14+/Android 8+ 原生 + Hybrid；
- **操作系统**：Linux 服务器；macOS/Windows 桌面；
- **国产化**：支持主流国产 CPU/OS/数据库/中间件 适配路线。

## 13.8 国际化与本地化

- 至少支持中/英；可扩展到繁体、日、韩；
- 货币、时区、日期/数字格式本地化；
- 多租户可独立设置语言与时区。

## 13.9 易用性

- **可访问性 WCAG 2.1 AA** 目标；
- 移动端关键路径 ≤ 3 步；
- 新用户引导（Onboarding Tour）、智能搜索、命令面板（Cmd-K）；
- 帮助中心与上下文提示。

## 13.10 AI 能力（增量）

| 能力 | 描述 |
| --- | --- |
| 智能问答 | 基于知识库/项目数据的 RAG 助理 |
| 自动状态报告 | 周期性生成 PM/PMO 周报与摘要 |
| 风险预测 | 历史项目训练的风险/延期预警模型 |
| 智能拆解 | 输入目标自动产出 WBS 草案 |
| 相似项目推荐 | 立项时推荐参考项目与经验 |
| 资源推荐 | 任务 → 候选执行人（基于技能/负载/历史） |
| 智能评论 | 会议纪要/IM 摘要 → 任务/风险 |
| 文档助手 | 模板填充、错别字、翻译、检索问答 |
