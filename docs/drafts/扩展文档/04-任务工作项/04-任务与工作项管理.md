# 4 任务与工作项管理

## 4.1 任务模型与层级

### 4.1.1 层级

- **Epic（史诗）** → **Feature（特性）** → **User Story（用户故事）** → **Task（任务）** → **Subtask（子任务）**
- 同时支持**WBS 视角**（阶段/可交付物/工作包）平行展示。
- 一个工作项可有 **双标签**：`敏捷类型` 与 `WBS 节点`，互为索引。

### 4.1.2 字段模型（核心）

| 字段 | 说明 |
| --- | --- |
| 标题、描述、编号（自动） | 必填 |
| 类型 | Epic / Feature / Story / Task / Bug / Spike |
| 状态 | Backlog / To Do / In Progress / Blocked / In Review / Done / Archived |
| 优先级 | P0/P1/P2/P3 或 MoSCoW |
| 严重度 | 对 Bug：S1/S2/S3/S4 |
| 负责人（Assignee） | 主负责人 1 人 |
| 关注人（Watcher） | 多选 |
| 协作人（Collaborator） | 多选 |
| 计划开始/结束 | 受项目日历影响 |
| 实际开始/完成 | 自动记录 |
| 预估工时（Estimate） | 人时/小时 |
| 实际工时（Actual） | 自动汇总工时单 |
| 剩余工时（Remaining） | 自动计算 |
| 父任务/子任务 | 自引用 |
| 前置任务（Predecessor） | 多对多 |
| 标签（Tag） | 多选，可按项目自定义 |
| 自定义字段 | 按项目/工作项类型配置 |
| 所属项目、所属 Sprint/迭代 | 关联 |
| 关联交付物/文档 | 链接 |
| 关联风险/问题/缺陷 | 链接 |
| RAG 状态 | 综合判定 |
| 受理人变更历史 | 审计 |

## 4.2 视图

### 4.2.1 列表视图

- 多列可配置、过滤、排序、分组、列冻结；
- **JQL/PQL 类查询语法**（如 `project = "X" AND assignee = currentUser() AND status != Done`）；
- 支持**保存视图**与**共享视图**。

### 4.2.2 看板视图

- 列=状态，可自定义；
- **WIP 限制**（在制品数量限制）+ 触发提示；
- 卡片支持拖拽、检查清单、附件、@人、评论；
- 跨泳道（按负责人/优先级/Sprint/标签）；
- 列汇总（卡片数、工时、阻塞数）。

### 4.2.3 甘特/时间线视图

- 树形甘特，支持拖拽、缩放、关键路径、依赖线、基线对比；
- 时间线（Roadmap）用于多项目/迭代规划。

### 4.2.4 日历视图

- 按开始/结束/截止展示，跨人日历合并。

### 4.2.5 思维导图/树视图

- 用于需求拆解与评审。

## 4.3 迭代（Sprint）与排期

### 4.3.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-4.3-01 | Sprint 配置：名称、起止日期、容量（按人/技能/可用天数）、目标（Goal） |
| FR-4.3-02 | Sprint 规划：拖入/拖出 Backlog，自动计算容量利用率 |
| FR-4.3-03 | Sprint 进行中：燃尽图、每日/实时更新、阻塞看板 |
| FR-4.3-04 | Sprint 评审与回顾：内置模板（演示、反馈、行动项） |
| FR-4.3-05 | 未完成项自动回流 Backlog，并保留历史 Sprint 归属 |
| FR-4.3-06 | 跨 Sprint 依赖自动提示 |
| FR-4.3-07 | 团队 Velocity 趋势图与预测 |

## 4.4 依赖、前置与阻塞

| 编号 | 需求描述 |
| --- | --- |
| FR-4.4-01 | 任务间依赖：FS / SS / FF / SF + Lag/Lead |
| FR-4.4-02 | **跨项目依赖**：通过 Program 关系或手工关联 |
| FR-4.4-03 | 自动计算**关键路径**，在甘特中红色高亮 |
| FR-4.4-04 | 阻塞原因必须分类（人员/资源/需求/外部/技术/合规），并可设解决期限与负责人 |
| FR-4.4-05 | 被阻塞任务不计入"已完成"，燃尽图给出阻塞提示 |
| FR-4.4-06 | 阻塞超期自动升级通知 |

## 4.5 通知与订阅

- 默认订阅：负责人、关注人、协作人、评论被@人；
- 自定义订阅规则（如"所有 P0 任务变更"）；
- 通知通道：站内、邮件、IM（企业微信/钉钉/飞书）、短信（高优）。
