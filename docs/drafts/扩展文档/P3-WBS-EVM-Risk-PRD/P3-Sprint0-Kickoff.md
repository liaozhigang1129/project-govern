## 1. 会议目标

### 1.1 3 个 Why

- **Why 1 (背景)**: 客户/PMO 反映 P1/P2 的项目管理还停在 Excel + 邮件, 缺 WBS 分解/挣值分析/风险可视化. P3 是补齐项目域"专业能力"的关键里程碑.
- **Why 2 (业务)**: 全市 50+ 项目, 1000+ 任务/项目, 当前无法回答"项目挣不挣钱? 进度是否健康? 风险在哪里?". P3 上线后回答这 3 个问题.
- **Why 3 (商业)**: Q3 续约关键, P3 演示是 SOW 第 3 里程碑 (40% 合同款), 不上线影响回款.

### 1.2 3 个目标 (Sprint 0 结束态)

1. **技术基线就绪**: 开发环境 / CI/CD / 库选型 / 协议锁定, 团队 5 人全部能跑通 hello world
2. **设计基线就绪**: 5 视图 (树/甘特/网络/EVM/矩阵) 线框 + 组件库选型 + 字段确认
3. **计划基线就绪**: 8 周甘特图 + 关键节点 (W2/W3/W5/W8) 评审机制 + 回滚预案演练

### 1.3 3 个非目标 (Sprint 0 不做)

- ❌ 不写业务代码 (W2 开始)
- ❌ 不接真实数据 (用 P2 的 mock 数据)
- ❌ 不发布灰度 (W6 才开始)
