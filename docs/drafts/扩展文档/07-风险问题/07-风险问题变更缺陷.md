# 7 风险、问题、变更、缺陷管理

## 7.1 风险管理

### 7.1.1 风险登记册（Risk Register）

| 字段 | 说明 |
| --- | --- |
| 风险编号 | 自动 |
| 标题、描述、类别 | 必填 |
| 风险来源 | 内部/外部；技术/资源/合规/市场/财务/... |
| 概率（P）| 1-5 |
| 影响（I） | 1-5 |
| 风险值 = P × I | 自动 |
| 风险等级 | 低/中/高/极高（阈值可配） |
| 触发条件 | 描述"风险事件化"的信号 |
| 风险责任人（Owner） | 单人 |
| 应对策略 | 规避/转移/减轻/接受/利用/分享 |
| 应对措施 | 多条，可指派/设截止日期 |
| 状态 | 已识别/分析中/应对中/已关闭/已发生（转问题） |
| 关闭日期、关闭说明 | 关闭时必填 |
| 关联项目/任务/WBS/预算 | 链接 |
| 经验教训 | 关闭后转经验库 |

### 7.1.2 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-7.1-01 | **风险矩阵（热力图）** 视图，按 P×I 自动落位 |
| FR-7.1-02 | 风险**到期检查**（应对措施到期/到期未关闭） |
| FR-7.1-03 | 风险**升级**：等级 ≥ 阈值时自动通知 Sponsor/PMO |
| FR-7.1-04 | 风险**复盘**：定期重新评估 P/I（与项目阶段挂钩） |
| FR-7.1-05 | 风险**模板库**：按行业/项目类型预置 |
| FR-7.1-06 | 风险**看板**：按状态/等级/责任人 |
| FR-7.1-07 | 与**挣值（EVM）/ 阶段评审**联动展示 |

## 7.2 问题管理（Issue）

- 区别于风险：问题=已发生，需要解决；
- 字段与风险类似，并增加：发现日期、影响范围、SLA、解决方案、根因分类、解决日期；
- 与**缺陷（Bug）**、**变更**可互转（按策略）。

## 7.3 变更管理（影响分析）

- 详细流程见 §3.4，此处强调：
  - 与**风险/问题/缺陷**的关联引用；
  - CCB 评审材料自动从 PMS 抽取（计划/预算/资源/进度影响）；
  - 变更实施后**回头验证**与**结项归档**。

## 7.4 缺陷管理（Bug，可与 ALM 集成）

### 7.4.1 内置简版

| 字段 | 标题、描述、复现步骤、期望/实际、截图/日志、环境、严重度、优先级、模块、指派、状态、SLA、关联任务/版本 |
| --- | --- |
| 生命周期 | New → Assigned → In Progress → Verified → Closed / Reopened |
| SLA | S1=4h 响应 / 24h 修复；S2=1 工作日 / 3 工作日；以此类推 |
| 缺陷密度 | 按模块/版本/迭代统计 |
| 缺陷逃逸率 | 生产环境 vs 测试环境 |

### 7.4.2 与 ALM 集成

- 支持与研发 ALM 双向同步；
- 字段映射配置；
- 同步策略：定时 / Webhook / 事件驱动。
