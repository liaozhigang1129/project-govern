# 5 资源与团队管理

## 5.1 组织架构

- 支持**多维组织树**：法人、事业部、职能部门、项目虚拟团队；
- 用户身份：内部员工、外包、合作伙伴、外部专家；
- 岗位（Position）与角色（Role）解耦：岗位 1:N 角色，角色 N:M 权限。

## 5.2 资源池与技能

### 5.2.1 资源池维度

- 部门、技能、岗位、可用性、成本中心、地理位置、时区、语言、出勤日历。

### 5.2.2 技能模型

| 字段 | 描述 |
| --- | --- |
| 技能名称 + 分类 | 业务、技术、管理、语言、合规等 |
| 等级 | 0-5 或 Novice/Intermediate/Advanced/Expert |
| 认证 | 证书/有效期 |
| 上次评估日期 | 评估人 |
| 项目经历 | 实际应用该技能的项目列表 |
| 意愿度 | 高/中/低 |

## 5.3 资源调度与分配

### 5.3.1 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-5.3-01 | 资源申请单：项目、角色、技能、级别、起止时间、占用率（50% / 100%） |
| FR-5.3-02 | 资源经理看板：**人员视角 + 项目视角** 双向看 |
| FR-5.3-03 | 冲突检测：同一人多项目时间窗冲突、超载（>100%） |
| FR-5.3-04 | 资源**预占（Soft Book）与确认（Hard Book）** 两阶段 |
| FR-5.3-05 | 资源**审批链**：PM 申请 → 资源经理 → 部门负责人 → PMO 备案 |
| FR-5.3-06 | 支持**快速替换**（人员变更最小化影响：技能相似度推荐） |
| FR-5.3-07 | **资源曲线**（使用率热力图）、**未来 N 周可用性预测** |
| FR-5.3-08 | 资源**轮转池/共享池**管理 |
| FR-5.3-09 | 资源**离职/转岗**时的项目交接与影响分析 |
| FR-5.3-10 | 与工时/任务实际占用**双向校验**，发现"挂名不上工" |

## 5.4 产能与日历

- 公司日历：节假日、弹性工作、调休、特殊营业日；
- 个人日历：请假、出差、培训、专注时间；
- 团队日历：节假日、值班、Sprint 周期；
- **产能（Capacity）** = 工作日 − 假期 − 请假 − 培训 − 已分配工时；
- **利用率（Utilization）** = 已分配工时 / 产能；
- 资源经理可设定**目标利用率**（如 80%）作为调度参考。

## 5.5 资源报表

- 资源全景：部门 × 月份 利用率热力；
- 个人维度：当前/历史项目占用、剩余产能、即将到期分配；
- 项目维度：人力成本占比、关键角色稳定性、关键人风险；
- 跨项目/跨部门借调报表。
