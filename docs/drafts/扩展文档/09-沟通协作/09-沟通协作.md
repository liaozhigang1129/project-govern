# 9 沟通协作与消息中心

## 9.1 评论与@

| 编号 | 需求描述 |
| --- | --- |
| FR-9.1-01 | 支持对项目/任务/文档/风险/问题/工时单/合同等所有对象的**评论** |
| FR-9.1-02 | **@人/角色/部门**，被@人收到通知；可批量@ |
| FR-9.1-03 | **表情回复**、**置顶**、**编辑历史**、**删除（保留痕迹）** |
| FR-9.1-04 | 评论中可**插入对象链接**（任务、文档、风险等） |
| FR-9.1-05 | 评论可转**任务**（一键转任务/风险/问题） |

## 9.2 消息中心

- **消息分类**：系统、订阅、@、审批、变更、预警、公告；
- **通知策略**：实时 / 汇总（如每天 18:00 汇总未读）；
- **勿扰时段**：尊重个人日历；
- **多端同步**：Web、移动、IM 插件桌面端；
- **未读/已读** 状态、批量已读、归档；
- **IM 深度集成**：企业微信/钉钉/飞书机器人；卡片化操作（审批/状态切换）；
- **邮件**：模板化、富文本、附件嵌入；
- **短信/电话**：仅高优（事故/合规告警）。

## 9.3 公告与项目空间

- **项目空间主页**：概览、动态、里程碑、团队、文档、风险热力；
- **公告**：租户/项目集/项目三级，支持确认阅读；
- **Wiki 风格项目主页**：拖拽组件（统计图、最新动态、待办、文档）。

## 9.4 会议与日程

- 与日历集成，发起会议、邀请、纪要模板；
- 会议纪要可转**行动项/任务**。
