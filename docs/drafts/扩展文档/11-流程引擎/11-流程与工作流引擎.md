# 11 流程与工作流引擎

## 11.1 引擎能力

| 编号 | 需求描述 |
| --- | --- |
| FR-11.1-01 | **可视化流程设计器**：基于 BPMN 2.0 子集（开始/结束/任务/网关/并行/会签/子流程） |
| FR-11.1-02 | **节点类型**：审批、填写、通知、抄送、自动化（脚本）、等待、Webhook、子流程 |
| FR-11.1-03 | **审批规则**：会签/或签/依次、加签/减签/转签、撤回/驳回/打回/通过 |
| FR-11.1-04 | **审批人来源**：角色、岗位、用户、字段引用（如项目 Sponsor）、HR 系统、上级链、矩阵主管 |
| FR-11.1-05 | **条件分支**：基于表单字段、当前节点、数据上下文 |
| FR-11.1-06 | **表单设计器**：拖拽字段、字段权限（可见/可编辑/必填）、校验规则、公式 |
| FR-11.1-07 | **流程版本**：发布后保留旧版本，已发起流程仍按发起时版本执行 |
| FR-11.1-08 | **流程 SLA**：单节点/全流程超时升级策略 |
| FR-11.1-09 | **流程监控**：平均耗时、超时率、瓶颈分析 |
| FR-11.1-10 | **流程仿真（Sandbox）**：用历史数据回放 |

## 11.2 业务流模板

- 立项流程（含评审）；
- 计划基线审批；
- 变更控制（Minor / Major / Critical）；
- 资源申请与释放；
- 风险升级；
- 文档审批与发布；
- 阶段评审（Stage Gate）；
- 结项审批；
- 费用报销、采购付款、合同会签；
- 工时补录/解锁。

## 11.3 与数据/状态联动

- 流程结束后**自动更新业务对象状态**（如：变更批准后基线更新、风险关闭、合同生效）；
- 流程表单字段**回写**到业务对象字段；
- 流程中可**关联**任务/工时/预算/风险。
