# 2 角色与权限模型

## 2.1 角色定义

### 2.1.1 系统级角色（平台级）

| 角色 | 描述 |
| --- | --- |
| 系统管理员（SysAdmin） | 平台初始化、组织/权限/字典/工作流配置 |
| 平台运营（PlatformOps） | 公告、模板、计费、租户、审计 |
| 安全审计员（Security Auditor） | 只读审计、导出与合规检查 |
| 集成管理员（IntegrationAdmin） | 第三方系统连接、密钥、限流、回调 |

### 2.1.2 PMO 治理角色

| 角色 | 描述 |
| --- | --- |
| PMO 总监（PMO Director） | 组合管理、治理与策略制定、最终审批 |
| PMO 经理（PMO Manager） | 项目集管理、阶段审计、组合报表 |
| PMO 专员（PMO Specialist） | 立项复核、模板维护、流程监督 |
| PMO 财务（PMO Finance） | 预算、成本、ROI 审核 |
| PMO 质量（PMO QA） | 质量、审计、复盘 |
| 业务负责人（Sponsor / Business Owner） | 业务方代表，立项与变更决策人 |

### 2.1.3 项目级角色

| 角色 | 描述 |
| --- | --- |
| 项目集经理（Program Manager） | 多项目协同、跨项目依赖与组合计划 |
| 项目经理（PM） | 项目全生命周期负责人 |
| 项目副经理 / 助理（Deputy PM / PMO Project） | 协助 PM 推动日常事务 |
| WBS 责任人（Work Package Owner） | 子工作包负责 |
| 任务执行人（Assignee） | 具体任务执行与工时填报 |
| 任务关注人（Watcher） | 关注但无操作权限 |
| 资源经理（Resource Manager） | 部门资源调度与排兵 |
| 部门负责人（Dept Head） | 部门资源审批、绩效与产能 |
| 评审专家（Reviewer） | 阶段评审、专家委员会 |
| 客户/外部干系人（External Stakeholder） | 受限的只读与有限评论 |

### 2.1.4 职能角色

财务（Finance）、HR、采购、法务、合规等系统单点登录即可访问与项目相关的审批与列表。

## 2.3 数据域隔离

- **租户隔离**：支持集团—子公司—部门多级租户；
- **项目域隔离**：按"可见范围（Public / Internal / Confidential / Restricted）"分级；
- **字段级权限**：对预算、合同金额、个人手机号等敏感字段做脱敏与按角色解密；
- **行级权限**：按部门/项目集/项目组成员控制数据可见；
- **数据所有权**：每个项目/工作项有"主数据所有者"，跨域访问需申请；
- **密级标识**：水印、访问日志、屏幕录像（可选）。
