### §2.5.2 4 学习曲线模型

> 不同角色采用不同的"学→练→战→评"曲线。

#### 曲线 A — 高管短循环（Sponsor）

```
[1h 简报] → [月度 15min 仪表盘演练] → [季度 1h 案例] → [年终 2h 复盘]
   E3            E4-E5 持续              E5                E5
```

- **频度**：低（每月 1 次 15 min）
- **形式**：高管简报 + 1 对 1 演示
- **产物**：高管 1 页决策卡片

#### 曲线 B — 业务专家深循环（PMO / 财务 / HR / Admin / 审计）

```
[2-3 天工作坊] → [2 周沙箱实操] → [1 周真实项目演练] → [认证考试] → [季度复训]
   E2/E3              E3               E3-E4            E3            E5
```

- **频度**：集中 + 间隔
- **形式**：工作坊 + 沙箱 + 真实演练
- **产物**：认证证书 + 试讲/演练视频

#### 曲线 C — 一线 PM 战循环（PM / KU）

```
[4 天核心课] → [2 周项目沙箱] → [上线期 Hot-line] → [1 月实战] → [2 月微课] → [季度认证]
   E3                E3                E4            E4          E5           E5
```

- **频度**：高（每日/每周）
- **形式**：工作坊 + 沙箱 + Hot-line + 微课
- **产物**：认证证书 + 案例贡献

#### 曲线 D — 广覆盖自助循环（团队 / 外部供应商 / IT Help Desk）

```
[1.5 h 录播] → [即时上下文帮助] → [按需微课] → [季度轻量复训]
   E3                E3-E5         E4-E5        E5
```

- **频度**：极低（按需）
- **形式**：录播 + 应用内引导 + 微课
- **产物**：完成记录

### §2.5.4 路径编排规则

| 规则 | 描述 |
| --- | --- |
| R1 必修先行 | 必修课排在 T-6 之前完成；选修课可放到稳态期 |
| R2 必修递进 | 课程难度按 SF1→SF2→SF3→SF4→SF5 递进；同族内部按编号顺序 |
| R3 角色耦合 | BU 负责人必须在所辖 PM 通过核心课后才能开始 |
| R4 KU 优先 | KU 必须先于本条线 PM 培训；KU TTT 必须在 T-6 之前完成 |
| R5 上线前清零 | T-1 周所有必修课通过率必须 ≥ 95%，否则延后切流 |
| R6 实战接力 | 培训结束后立即进入实战陪跑（E4 Hot-line） |
