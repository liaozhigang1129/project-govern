# A6 培训赋能与变革管理（Training Enablement & Change Management）— 总索引

> 本系列文档聚焦"系统建好之后,人能不能用起来"——为 PMO 实施团队、HR/培训管理员、各业务条线项目经理、关键用户、Sponsor 提供从角色画像→培训矩阵→赋能路径→认证体系→采纳度跟踪→效果评估的完整方案。
> 配套主文档：SRS §2 角色与权限、A1 数据字典 users/roles、A2 API 规范 Part8（认证授权）、A3 UI 原型（界面操作是培训素材源）、A5 上线计划（培训排期与上线里程碑对齐）、A4 数据迁移（培训对象数据回填）。

---

## A6.0 系列总览

| 维度 | 内容 |
| --- | --- |
| 目标 | 把"会用、爱用、产生业务结果"作为交付目标，避免建成就束之高阁 |
| 适用对象 | Sponsor / PMO / 各角色用户 / IT 支持 / 培训管理员 / 外部伙伴 |
| 时间窗 | T-12 周到 T+12 周（与 A5 上线计划对齐） |
| 衡量北极星 | **采纳度 (Adoption Rate) = 30 日活跃用户数 / 应活跃用户数 ≥ 80%** |
| 三大支撑 | 1) 角色画像与培训需求；2) 课程与认证体系；3) 培训交付与跟踪闭环 |
