# 移动端 H5(Mobile Timesheet)

> 本 Spec 定义移动端 H5 的**功能范围、信息架构、关键交互、性能/可访问性策略**。
> 对应 wireframe:`source §8 — 移动端工时填报`(620 行级 ASCII 原型)。
> 治理与移动组合仪表盘见 [`reporting.md`](reporting.md);
> 前端架构基线见 [`frontend.md`](frontend.md)。

---

## 1. 产品定位

- **目标用户**:任务执行人(EXEC/PM/资源)
- **核心场景**:每周工时填报(高频、低门槛、离线可用)
- **MVP 范围**:**仅 Web H5**(SPA + 响应式),不开发原生 App
- **理由**:见 [STATUS.md](../STATUS.md) M7 阶段"v5 移动端原生 App 立项再评估"
  — 先用 H5 验证业务价值,再决定是否原生。

---

## 2. 信息架构

```
+--------------------------------+
| StatusBar (系统状态)            |
+--------------------------------+
| Header:  本周工时    [⚙]        |
+--------------------------------+
| 周选择器: [< 4/14-4/20 >]  [本周] |
+--------------------------------+
| 进度条: ▓▓▓▓▓░░░ 28h / 40h (70%) |
| 还差 12h, 3 天剩余              |
+--------------------------------+
| 每日卡片(周一→周日,折叠)        |
|  - 已填时长 / 目标 8h           |
|  - 项目/任务条目(可滑动)        |
|  - 加班/请假/补录切换           |
+--------------------------------+
| FAB: [+] 添加工时(含扫码)      |
+--------------------------------+
| BottomBar: 工时 | 任务 | 通知 | 我的 |
+--------------------------------+
```

## 3. 4 个核心页面(基于现有 SPA 路由)

| Tab | 路由(相对主应用) | 说明 |
| --- | --- | --- |
| **工时** | `/m/timesheet` | 周视图 + 日卡片 + FAB 添加工时 |
| **任务** | `/m/tasks` | 我的任务列表(可扫码) |
| **通知** | `/m/notifications` | 审批待办 + 提醒(卡片式) |
| **我的** | `/m/me` | 工时统计 + 设置 + 报销入口 |

> H5 与桌面端共享同一 Vue 3 SPA,**响应式断点 < 768px 自动切移动端布局**
> (沿用 reporting.md §1 的"移动端摘要视图"约定)。

## 4. 添加工时弹层(FAB → 弹层)

字段:
- 日期选择(默认今日)
- 项目(搜索 / 收藏 / 最近)
- 任务(搜索 + 扫码 📷)
- 时长(快捷:1h / 2h / 4h / 8h / 全天)
- 类型:工作 / 加班 / 请假
- 描述(≥ 5 字符必填)
- 附件 / @人

操作:[取消] [保存草稿] [提交]

---

## 5. 关键交互

| 交互 | 实现 |
| --- | --- |
| 周切换 | 上下周按钮 + 自定义日期范围 |
| 日折叠 | tap 展开 / 折叠 |
| 条目左滑 | 编辑 / 删除(滑出 50% 触发) |
| 长按拖拽 | 跨日移动工时条目 |
| 扫码 @任务 | `getUserMedia` + ZXing / Quagga JS |
| 复制昨日 | 整日条目一键复制 |
| 离线缓存 | IndexedDB(5 周历史 + 项目/任务字典) |
| 提交 | 草稿 → 提交(走现有 `TimesheetController`) |

## 6. 性能预算

| 指标 | 目标 |
| --- | --- |
| **首屏** | < 1s(骨架屏 + 渐进加载) |
| **滑动帧率** | 60fps(虚拟列表 + 懒加载) |
| **图片懒加载** | IntersectionObserver |
| **本地缓存** | 5 周数据(项目 / 任务 / 工时) |
| **预取** | 周切换时预取下一周 |

## 8. 可访问性(A11y)

- 字号自适应:系统字号 + 应用内 ±2 级
- 触控目标 ≥ 44pt(iOS)/ 48dp(Android)
- 屏幕阅读器:每条目朗读"项目 + 任务 + 时长 + 状态"
- 颜色对比度 ≥ 4.5:1
- "减少动效" 模式下禁用滚动动画
- 语音输入 / Voice Control 友好

---

## 9. 业务规则(强制)

| 规则 | 说明 |
| --- | --- |
| **每日上限** | 工作 12h + 加班 4h = 16h(>12h 弹主管确认) |
| **每周目标** | 40h(可按部门配置) |
| **跨周修改** | 已提交工时不允修改,需审批解锁 |
| **类型切换** | 工作 → 加班 = 增加预算占用;请假 = 释放产能 |
| **必填项** | 项目 + 任务 + 时长 + 描述(≥ 5 字符) |
| **批量提交** | > 3 项需二次确认 |
| **逾期提醒** | 每周一 9:00 推送未填 |
| **强制回执** | 月底 / 季底 / 项目结束前 100% 填齐才允许签字 |

---

## 10. 隐私与安全

- 截屏禁用(敏感项目可配置)
- 移动设备绑定(首次激活 + 二次确认)
- 远程擦除(离职 / 丢失时)
- VPN / 零信任网络访问
- 拍照附件不保留本地副本(仅上传)
- 定位数据可选,开启需用户授权

## 11. 通知与提醒

| 场景 | 渠道 | 时机 |
| --- | --- | --- |

| 审批通过 / 驳回 | Push + IM | 即时 |

| 项目变更 | Push | 即时 |

## 13. 验收标准(草案)

- H5 在 iPhone 14 Pro / Android 中端机 上首屏 < 1s
- 工时报错率 < 0.1%(离线缓存恢复后无丢失)
- 9 项业务规则全部生效
- A11y 通过 axe-core 自动化检测
- Web Vitals:LCP < 2.5s / FID < 100ms / CLS < 0.1
